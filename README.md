# Fitness Planner

A PHP and MySQL-based fitness planning and progress tracking web application that generates personalized diet and workout plans based on user goals and fitness information.

## Features

- User registration and login
- User profile management
- Personalized fitness plan generation
- Diet and workout plan generation
- BMI calculation
- BMR and TDEE calculation
- Daily calorie recommendations
- Macronutrient breakdown
- Multiple fitness goals:
  - Weight Loss
  - Muscle Gain
  - Bulking
  - Maintenance
- Progress tracking
- Weight and body measurement history
- Saved fitness plans
- Plan viewing and deletion
- Responsive web interface

## Tech Stack

- HTML
- CSS
- JavaScript
- PHP
- MySQL
- XAMPP
